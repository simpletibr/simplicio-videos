# simplicio-videos

> Детерминированный видеодвижок, управляемый агентами: на входе YAML-контракт, на выходе MP4, а вокруг — инструменты для аудио, видео, голоса, замены персонажа, планирования публикаций в соцсетях, лицензированных ресурсов и веб-поиска.

[Английский и все языки: основной README](../README.md) · [Португальский](../README.pt-BR.md)

## Что это делает

- **Контракт в MP4:** проверяет YAML-контракт, генерирует озвучку, выполняет детерминированный рендер в HyperFrames с микшем на -14 LUFS и записывает манифест. В пути рендера LLM не участвует.
- **Голос:** провайдеры `file`, `local` (Kokoro-82M), `gemini`, `voxcpm`, `openvoice` и `voicestudio` (локальное приложение). `elevenlabs` и `xai` — заглушки (stubs), не реализованы.
- **Аудио и видео (`media`):** проба, извлечение аудио, листы кадров, субтитры, маскирование области, дубляж и загрузка одного публичного видео с записью происхождения (provenance).
- **Вертикальные нарезки (`shorts`):** клипы 9:16 из длинного видео, оцениваемые фиксированными правилами по транскрипции слов.
- **Монтаж по EDL (`edit`):** агент пишет EDL, вспомогательные инструменты video-use (зафиксированная версия) запускают ffmpeg.
- **Шаблоны и каталоги:** 14 отраслевых шаблонов (8 готовы к рендеру), 55 записей каталога движения, 50 форматов рекламы и 50 углов подачи.
- **Замена персонажа и задачи (`swap`, `jobs`):** платная замена через шесть адаптеров, с оценкой стоимости и лимитом в USD, только из терминала; фоновые задачи для swap и локального голоса.
- **Внешние треки:** Hypit, OpenMontage, OpenCut, Toonflow и MoneyPrinterTurbo, каждый зафиксирован и запускается как отдельная программа, никогда не импортируется.
- **Планирование публикаций (`social`):** проверяет видео по лимитам каждой сети и пишет план. **Никогда не публикует.**
- **Лицензированная библиотека (`openverse`):** поиск, безопасная загрузка, проверка каждого запроса и экспорт с указанием авторов (credits).
- **Веб-поиск (`busca`):** запросы и чтение страниц через TinyFish, с источником и датой для каждого результата и дневным лимитом вызовов.
- **Трек UGC:** файлы промптов для синтетических персонажей и ручной пайплайн, вне рендера.
- **Интеграция с агентами:** MCP-сервер с 19 инструментами `video.*`, шесть skills и `install` для 11 агентских хостов.
- **Эксплуатация:** статус, зафиксированные инструменты, диагностика, рабочее пространство, обновления и общий вход в Simplicio.

## Быстрый старт

```bash
gh repo clone simpletibr/simplicio-videos && cd simplicio-videos
pip install -e .                      # `simplicio-video` command (Python >= 3.10); rendering needs Node >= 22 and ffmpeg
simplicio-video setup                 # first run
simplicio-video install               # copy the skills into your agent host (project; --global for the home folder)
simplicio-video doctor                # check what is missing

cd clients/<cliente>/<campanha>       # a client project with a contract.yaml
simplicio-video validate contract.yaml
simplicio-video voice contract.yaml   # narration; local draft voice or --provider file|gemini|voxcpm|openvoice|voicestudio
simplicio-video render contract.yaml  # out/<cliente>-<campanha>.mp4 + render.manifest.json
```

## Ограничения

- **Покрытие MCP:** `media`, `shorts`, `tools`, `status`, `doctor` и `install` пока доступны только через CLI.
- **Непроверенные адаптеры замены:** `fal`, `wavespeed`, `kie` и `alibaba` написаны по публичной документации и не проверены на работающих API.
- **Без публикации:** движок никогда не публикует и не загружает ничего в социальные сети.
- **Платформы:** пакет классифицирован для Linux; macOS и Windows не подтверждены на реальных машинах.
