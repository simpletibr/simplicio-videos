# Recursos coletados (ferramentas de vídeo/motion)

Estrelas conferidas via GitHub API em 30/09/2026.

### Vídeo programático (código → vídeo)
- [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) — ⭐54.5k · TS · Apache-2.0. HTML → vídeo feito para agentes (GSAP, Chrome headless, FFmpeg), skills para Claude Code/Codex. **Base deste repo.**
- [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) — ⭐10k · Apache-2.0. Skill de Claude Code/Codex: vídeos de produto cinematográficos em Remotion, 152 shot recipe cards, 209 motion previews, template pronto.
- [echris6/motion-video-kit](https://github.com/echris6/motion-video-kit) — ⭐416 · MIT (texto, scripts e templates). Skill de Claude Code (`business-motion-film`, também usável como contexto para qualquer LLM) para comerciais curtos (15–40 s) "estilo launch film" de negócios reais: footage gerado por IA + motion em HTML/GSAP + Three.js seletivo. Traz o loop de revisão **Gauntlet** (quem constrói ≠ quem julga; crítico novo a cada rodada, com prompts prontos), **gramática de motion** (6 regras + catálogo de mecanismos, notas sobre 28 launch films — só links), **barra de qualidade** medida (tempo congelado, loudness, contraste, cor da marca, determinismo por seek), regras de áudio, playbook de ofertas por vertical, padrões Three.js determinísticos e scripts ffmpeg (`frozen-time.sh`, `loudness.sh`, `contact-sheet.sh`). Recomenda HyperFrames para render. Usado como fonte de 5 padrões `proposto` em `motion/`.
- [mexicat/pdoom-video](https://github.com/mexicat/pdoom-video) — ⭐2k · MIT. Videoclipe 100% renderizado em código (three.js), feito com Opus 5.5 no Claude Code.
