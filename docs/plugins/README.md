# Plugins

Plugins de primeira parte, descobertos pelo registro ([host de plugins](../host/plugin-host.md)):

- [Studio (Draft e marca viram vídeo)](studio.md): comandos `make`, `make preview` e `draft show`.
- [Media (orçamento e aprovação de gasto)](media.md): comandos `generate quote`, `generate approve` e `generate show`.

Cada plugin tem uma página nesta pasta com front matter (`title`, `summary`, `commands`, `issue` e `last_verified`). O mapa de plugins do README e do AGENTS.md sai dessas páginas com `make regen`. Os plugins instalados aparecem em [reference/plugins.md](../reference/plugins.md).
