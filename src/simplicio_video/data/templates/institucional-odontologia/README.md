# institucional-odontologia — pronto (venda ativa, fora de data comemorativa)

Vídeo institucional de 16 s (9:16, 128 BPM) para clínicas e consultórios odontológicos, para uso fora do Dia das Crianças
(venda ativa, fora do CLI do motor). Mesmo ritmo e câmera do piloto de odontologia (v02)
(punch/whip nos cortes, palavra a palavra, mascote `tooth-character` + `toothbrush-sparkle`), estrelas nas batidas **sem
confete nem balões**, trilha `institucional` com bateria suave (0,6). Voz **Laomedeia** (reserva Achernar), leva animada.

| Cena | Fala (Laomedeia, animada e calorosa) | Tela |
|---|---|---|
| s1 | "Seu sorriso merece cuidado!" | Seu sorriso / merece / cuidado! |
| s2 | "Cuidar da saúde bucal é cuidar de você." | mascote "Olá!" + texto |
| s3 | "Consultas regulares mantêm o sorriso saudável." (curta: "Consultas regulares cuidam do sorriso.") | escova + texto |
| s4 | "Conheça {nome}." | logo real, NOME / SUB, "cuidando do seu sorriso", @, cidade |

Cuidados (CFO, Res. 196/2019 e Código de Ética Odontológica): sem antes/depois, sem promessa de resultado, sem preço/desconto,
sem superlativos. Logo só o real da empresa (site/Instagram dela, coluna `logo`/`logo_url`).
